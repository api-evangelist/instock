# Instock

> Instock is a robotics company delivering a goods-to-person automated storage and retrieval system (ASRS) as fulfillment robotics-as-a-service (RaaS). Its Incloud cloud platform exposes a REST API so customer host systems (PIM/IMS/OMS) can manage sites, articles (SKUs), orders, order tasks, inventory, and article moves. REST over HTTPS, JSON bodies, Bearer-token (JWT) auth, cursor pagination, snake_case, RFC 3339 timestamps. Backed by Lux Capital.

## APIs

- [Instock API reference](https://instock.com/en/docs/api/): REST API for the Instock ASRS (Incloud). Base URL https://api.instock.com/v1.
- [OpenAPI 3.1 definition](https://raw.githubusercontent.com/api-evangelist/instock/refs/heads/main/openapi/instock-openapi.json): 19 operations across Sites, Articles, Orders, Ordertasks, Inventory, and Moves.
